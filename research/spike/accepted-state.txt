Objective acc:obj1 (open) — "Decide what TypeScript's control flow analysis should assume
about the side effects of an intervening function call."

Decision acc:d1 (active), decided_by ahejlsberg — "TypeScript keeps the optimistic assumption
that type guards are unaffected by intervening function calls; in aggregate the extra narrowing
catches far more real bugs than it causes false errors."

Decision acc:d2 (active), decided_by ahejlsberg — "The TypeScript compiler's own parser will
read the current token through a `token()` function rather than a mutable `token` variable, so
that narrowing is suppressed at those sites."
