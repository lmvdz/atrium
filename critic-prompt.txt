WHAT THE CODE IS. Atrium turns chat messages into accepted objects (decision, commitment, open_question, claim, objective). A language model reads a window of messages and stages a `Proposal` carrying a `quote` (a span it says it read the object out of) and a payload with a statement. Deterministic checks then decide whether that reading may become a fact with no human involved. The cardinal defect class, found repeatedly in earlier rounds, is a receipt that looks perfect while the record it produces says something the named person did not say — e.g. quoting "Bob will not deploy production Friday" and minting "Bob will deploy production Friday".
